# Validation Open-Day 0.3.0

Date : 15 juillet 2026.

## Périmètre livré

- parcours guidé `project` et trois modes persistés ;
- transitions automatiques limitées aux étapes sûres ;
- portes humaines et commande d'application distincte ;
- correction publique bornée d'un candidat ;
- tests humains sans shell dans un worktree jetable ;
- journal des tests, timeout, annulation et récupération ;
- lease d'exécution et récupération conservatrice des coûts incertains ;
- état `APPLYING` et réconciliation Git après interruption ;
- smoke test du parcours guidé complet avec correction et tests.

## Résultats

Environnement de validation : Node.js 24.14.0, npm 11.9.0 et Git 2.51.1.

- `npm run typecheck` : réussi avec TypeScript strict ;
- `npm test` : 9 fichiers et 61 tests réussis ;
- `npm run build` : binaire CJS compilé ;
- `npm run smoke` : session manuelle de référence avec 98 événements, puis
  cycle guidé complet réussi avec une correction, deux tests de candidat et
  une campagne simulée de quatre conditions ;
- `npm run package:check` : archive npm créée, installée dans un répertoire
  vierge, binaire `open-day 0.3.0` exécuté et licences des cinq dépendances
  directes vérifiées ;
- `npm audit --audit-level=moderate` : 0 vulnérabilité connue ;
- `npm audit --omit=dev --audit-level=moderate` : 0 vulnérabilité de production
  connue ;
- `npm run check` : chaîne complète réussie sans étape ignorée.

Les tests couvrent notamment les deux modes d'exécution, les portes humaines,
la limite de correction, succès/échec/timeout/exécutable absent d'un test, la
récupération d'un test orphelin, l'annulation fournisseur, les chemins et liens
symboliques, le budget, la récupération conservatrice d'un appel et la
réconciliation de `git apply` avant et après application effective, ainsi que
la migration incrémentale d'une base 0.2.

Le smoke et les tests utilisent le runtime déterministe. Ils prouvent les
transitions, invariants de sécurité et artefacts, pas un gain de qualité des
modèles.

Les adaptateurs OpenAI, Anthropic et Google sont validés par tests de contrat
avec clients simulés. Aucun appel réel n'a été lancé, les clés et tarifs n'étant
pas configurés dans l'environnement de release.
