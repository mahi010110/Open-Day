# Validation du prototype 0.2.0

Date : 15 juillet 2026.

## Verdict

Le paquet est utilisable localement pour délibérer, figer une conception puis
produire et appliquer sous contrôle humain des candidats de fichiers issus de
deux topologies multi-agents. Ce verdict porte sur le logiciel et ses barrières,
pas sur la qualité supérieure du multi-agent.

## Vérifications automatisées

La commande de release est :

```bash
npm run check
```

Elle couvre notamment :

- typage TypeScript strict ;
- machines à états de conception et d'exécution ;
- budgets, événements immuables et validations humaines ;
- contrats OpenAI, Anthropic et Google pour la délibération et les sorties de
  fichiers structurées ;
- modes `COORDINATED` et `COMPETITIVE` de bout en bout ;
- quatre worktrees distincts, intégration et synthèse ;
- dépôt principal intact avant `exec-apply` ;
- opérations `CREATE`, `UPDATE` et `DELETE` avec hashes ;
- refus d'un dépôt sale et d'une traversée par lien symbolique ;
- annulation en cours depuis un autre processus ;
- compilation du binaire, session de conception complète, exécution concurrente
  complète et campagne d'évaluation simulée ;
- emballage, installation vierge et version 0.2.0 du paquet npm.

Résultat de référence attendu : 8 fichiers de tests et 54 tests réussis. Le
smoke test produit une session `COMPLETED`, une exécution `APPLIED` et quatre
rapports expérimentaux sans réseau.

## Non validé

- aucun appel facturable n'a été envoyé ;
- aucune compilation ou suite de tests n'est exécutée sur du code généré ;
- la reprise après `SIGKILL` pendant l'exécution n'est pas livrée ;
- la supériorité en qualité du mode coordonné ou concurrent n'est pas établie ;
- aucun dépôt confidentiel ou réglementé n'a été utilisé.

## Risques acceptés pour le pilote

- `node:sqlite` reste signalé expérimental sous Node 24 ;
- l'estimation de coût dépend des tarifs saisis par l'utilisateur ;
- les contextes volumineux sont bornés et peuvent être incomplets ;
- le filtre de secrets est défensif mais non exhaustif ;
- les worktrees restent présents après la session ;
- un crash entre l'application Git et le marquage SQLite nécessite une
  vérification manuelle.
